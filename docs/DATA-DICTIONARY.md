# 门店低销预警台数据字典

## 日销文件（来源）

| 字段 | 定义 |
|---|---|
| 门店编号 | 文本主键，保留前导零。按「门店 + 营业日期」归并版本，不跨门店汇并。 |
| 修订号 | 正整数。同门店同日最高版优先；最高同版字段冲突隔离，旧版无法接替；存在未采信的更高坏版本时旧版记 `REV_BLOCKED`。 |
| 提交时间 | ISO 8601，必须带 UTC 偏移量，归一后展示 UTC。 |
| 营业日期 | `YYYY-MM-DD`，须落在本财年内。 |
| 营业状态 | `营业` / `停业` / `缺报`。停业是计划内不营业；缺报是应报未报。其他值记 `STATUS_INVALID`。 |
| 本年日销售 | 定点小数，单位元。营业状态必填；停业/缺报留空。 |
| 上年同星期日销售 | 基准值，可空。留空表示该日无上年基准，归为不可比 `NO_BASELINE`，不算走弱。 |
| 原始备注 | 可空，允许引号内换行。 |

旧版别名：`门店编码`/`门店号`→门店编号，`版本`→修订号，`更新时刻`→提交时间，`当日销售额`→本年日销售，`基准销售额`→上年同星期日销售，`备注`→原始备注。新旧名同时出现拒绝。`-`、`N/A`、`NULL`、`未知`、空串按必填缺失处理。识别 UTF-8、UTF-8 BOM 与 GB18030。单文件上限 128 KiB。

## 门店清单（第二输入）

表头固定为 `门店编号,门店名称,区域`。重复门店编号整单拒绝（`BOOK_CONFLICT`）。清单外的门店保留编号并标注「未登记门店」，不影响检测。

## 财周日历与对照

- 四四五财年：期首为周一，每季 13 周（4+4+5），全年 52 周；上年可含第 53 闰周。
- 本财年期首 `2025-01-06`，上年期首 `2024-01-01`（53 周），两期首尾相接。
- 营业日 `d` 的基准 = 上年**同财周序号、同星期**的营业日。本年第 53 周无对应（本年只有 52 周），越界记 `FISCAL_SPAN`。
- 阈值 = 基准 × `0.80`（定点保留两位）。本年值 **严格小于** 阈值记 `WEAK`，等于或超过记 `OK`。零销售是有效营业记录。

## 单日原因码

| 代码 | 含义 | 是否可比 |
|---|---|---|
| `WEAK` | 低于同星期基准八成 | 是（走弱） |
| `OK` | 达到基准八成 | 是（达标，断开区间） |
| `NOT_OPEN` | 计划停业 | 否（缺口，留痕） |
| `BASE_MISSING` | 当日缺报 | 否（缺口，留痕） |
| `NO_BASELINE` | 无上年同星期基准 | 否 |
| `FISCAL_SPAN` / `FISCAL_LEAP` | 越界 / 闰周无配对 | 坏行隔离 |
| `REQUIRED` / `STATUS_INVALID` / `NUMBER` / `RANGE` / `DATE` / `TIMESTAMP` | 字段与格式问题 | 坏行隔离 |
| `REV_CONFLICT` / `SUPERSEDED` / `EXACT_DUP` / `REV_BLOCKED` | 版本归并 | 隔离或替换留痕 |

## 区间检测与预警台账

- 触发：累计 `TRIGGER_DAYS=2` 个走弱营业日；`GAP_TOLERANCE=1`，即连续 1 个不可比日不断区间，第 2 个连续不可比日断开。
- 区间字段：`start_day`（首个走弱日）、`trigger_day`（第 2 个走弱日）、`end_day`（最后走弱日）、`weak_days`、`gap_days`、`fiscal_weeks`、`cross_week`。
- 台账表 `alerts` 以 `(门店编号, start_day)` 为主键，状态 `open` / `confirmed`。
- 留痕 `corrections`：`LATE_DATA`（迟到数据想缩短区间，保留原结论）、`NOT_REPRODUCED`（本批未复现）、`BLOCKED_LOCKED_STORE`（已确认门店的新区间拒收）。
- 批次指纹 `run_id = sha256(规则版本:来源哈希:清单哈希:阈值参数)`；同字节同参数重跑是同一批次。
- `confirmations` 记录已确认批次；确认后该批次门店与区间锁定，重跑不回退、不新增。

## 随附算例（cases.csv）

| 算例 | 预期代码 | 可核明细 |
|---|---|---|
| `weak_day` | `WEAK` | 阈值 800.00，降幅 -300 |
| `ok_day` | `OK` | 恰好 800 不触发 |
| `closed_day` | `NOT_OPEN` | 计划停业、不可比 |
| `missing_day` | `BASE_MISSING` | 缺报、不可比但留痕 |
| `no_baseline` | `NO_BASELINE` | 无基准不算走弱 |

样例门店预期：`00101`（停业缺口不断区间）、`00103`（缺报缺口）、`00104`（连续两缺口断开）、`00105`（跨财周不拆段）、`00108`（无基准日后触发）产生预警；`00102` 单日走弱、`00106` 修订后达标，不触发。
